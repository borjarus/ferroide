# Code of Conduct

FerroIDE adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short:

- Be respectful and welcoming, whatever someone's experience, background or
  identity.
- Give and accept constructive feedback gracefully; critique code, not people.
- Harassment, insults, and personal or political attacks are not tolerated,
  in any project space or in public spaces when representing the project.

## Reporting

Report unacceptable behavior privately to the maintainers at
**public.mila@gmail.com** (to be set up before the repository is made public).
Reports are handled confidentially, and the maintainers will follow the
Contributor Covenant's enforcement guidelines: correction, warning, temporary
ban, permanent ban.
